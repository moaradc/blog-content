      3. 长代码测试 (测试展开功能)

      当代码较长时，应显示滚动条或通过 CSS 限制高度（配合 expand-btn 逻辑）。

      /* 全局重置 */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

body {
    background-color: #f5f5f5;
    font-family: 'Noto Sans SC', sans-serif;
    line-height: 1.6;
    color: #333;
}

.header {
    background: #222;
    color: #fff;
    padding: 20px;
    text-align: center;
}

.nav-link {
    color: #fff;
    text-decoration: none;
    margin: 0 10px;
}

.nav-link:hover {
    color: #00adb5;
}

/* 底部样式 */
footer {
    margin-top: 50px;
    padding: 20px;
    border-top: 1px solid #ddd;
    text-align: center;
    font-size: 0.9rem;
}

flowchart TD

    C --> E[渲染 marked]

    D --> E

    E --> F{是否含代码块}

sequenceDiagram

    U->>F: 打开 /details/article?id=103

    F->>R: fetch posts.json

    R-->>F: 文章元数据

    F->>R: fetch [103.md](http://103.md)

    R-->>F: markdown 内容

    F->>F: marked.parse + hljs

    F->>W: 加载评论组件

    W-->>U: 渲染评论框
